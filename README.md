# AI-Driven Intrusion Detection System (IDS)

## Project Summary

AI-Driven IDS is a Python-based cybersecurity project designed to process Snort intrusion detection alerts, organize security event data, and generate AI-assisted attack analysis reports.

The system uses Python to process Snort security logs and convert alert information into structured JSON files. It integrates the OpenRouter API to provide AI-assisted threat explanations, security insights, and recommended mitigation measures. The application also provides a Flask-based web dashboard to display detected security alerts and supports downloadable PDF reports for security analysis and documentation.

The project now includes **Docker support**, allowing the application and its Python dependencies to be packaged into a Docker image and run inside a container. A Dockerfile defines the application setup and startup process, while `requirements.txt` manages the required Python libraries. The `.dockerignore` and `.gitignore` files help exclude unnecessary files, generated data, and sensitive configuration from Docker builds and Git tracking. An `.env.example` file provides a template for configuring environment variables such as the OpenRouter API key.

## Key Features

- **Snort Alert Processing:** Processes intrusion detection alerts generated by Snort.
- **JSON Data Management:** Converts and stores alert records and summary information in structured JSON files.
- **AI-Assisted Threat Analysis:** Integrates OpenRouter API to explain potential threats and recommend mitigation measures.
- **Web-Based Dashboard:** Uses Flask to display and review detected security alerts through a browser interface.
- **PDF Report Generation:** Generates downloadable PDF reports containing attack information, AI-assisted analysis, and recommended mitigation steps.
- **Threat Analysis:** Helps users understand suspicious network activity and review security events.
- **Docker Containerization:** Packages the application and its Python dependencies into a Docker image for consistent deployment.
- **Environment Configuration:** Uses environment variables and `.env.example` for application configuration and API key management.
- **Version Control:** Uses Git and GitHub to manage and publish project source code.

## Technologies Used

Python • Snort 3 IDS • Flask • Docker • Dockerfile • OpenRouter API • JSON • HTML • CSS • Git • GitHub

## Project Workflow

Snort Network Monitoring → Security Alert Generation → Python Alert Processing → JSON Data Storage → Flask Web Dashboard → AI-Assisted Threat Analysis → Alert Visualization → PDF Report Generation

**Docker Deployment Workflow:**

Dockerfile → Docker Image → Docker Container → Flask Application → Web Dashboard

## Project Objective

The objective of this project is to simplify security alert analysis, improve understanding of potential cyber threats, and make security findings easier to review, analyze, and share. Docker support also helps make application deployment more consistent across different Docker-compatible environments.

## Disclaimer

This project is intended for educational purposes and authorized security testing. AI-generated analysis is advisory and should be verified against the original security alerts. Docker containerization does not automatically deploy or configure Snort on other systems. Automatic attack prevention is not claimed unless separately implemented and tested.
