# ai-driven-ids
AI-Driven Intrusion Detection System (IDS)

##Project Summary

AI-Driven IDS is a Python-based cybersecurity project that processes Snort security alerts, organizes alert data, and generates AI-assisted attack analysis reports.

The project uses Python to process Snort logs and store alert information in JSON files. It integrates the OpenRouter API to analyze security events, explain potential threats, and recommend mitigation measures. The application also supports generating downloadable PDF reports for security analysis and documentation.

##Key Features

Snort Alert Processing: Processes intrusion detection alerts generated by Snort.

JSON Data Management: Stores alert records and summary information in JSON files.

AI-Powered Analysis: Uses OpenRouter for AI-assisted threat explanations and security recommendations.

Security Application: Provides an application interface for working with alert data.

PDF Report Generation: Creates reports containing attack information and recommended mitigation steps.

Threat Analysis: Helps users understand suspicious network activity and review security events.

##Technologies Used

Python • Snort IDS • Flask • OpenRouter API • JSON • HTML • CSS • GitHub

##Project Workflow

Snort Alerts → Python Processing → JSON Data → Application → AI-Assisted Analysis → alert showing in dashboard → PDF Reports

##Project Objective

The goal is to simplify security alert analysis, improve understanding of potential cyber threats, and make security findings easier to review and share.
